# 4D-ID™

**OBSERVE → GROUND → IDENTIFY → RESOLVE → INTEROPERATE**

4D-ID starts after perception or an existing data system has produced an observation or record. It is a candidate standard for persistent identity, aliases, resolution, relationships, representations, state/time, provenance, and merge/split/history/reconciliation.

Grounding determines the referent; localization estimates where it is; 4D-ID preserves which thing that referent is across records and systems. An observation is evidence about something, not the persistent identity itself.

It does **not** perform detection, segmentation, SLAM, VPS, localization, geometric registration, rendering, navigation, or grasp planning. SEGS is adjacent, not core.
