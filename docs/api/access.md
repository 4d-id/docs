# Access API

The access operations (specification Clause 10) are one semantic API with many bindings. The REST binding is described in [openapi.yaml](https://github.com/4d-id/spec/blob/main/openapi/openapi.yaml). Operations: `resolve`, `get_entity`, `get_state`, `get_relations`, `query`, `query_events`, `transform`, `get_representations`, `get_snapshot`, `list`, `watch`, `context`.
