# The specification

4D-ID is a candidate standard until adopted. It starts after perception or an existing data system has supplied an observation or record. It defines persistent identity, aliases, resolution, relationships, representations, state/time, provenance, and merge/split/history/reconciliation.

It does not define or perform detection, segmentation, SLAM, VPS, localization, geometric registration, rendering, navigation, or grasp planning. SEGS is adjacent, not core.

The full text lives in the [spec repository](https://github.com/4d-id/spec/tree/main/parts). Start with [Part 1: Core](https://github.com/4d-id/spec/blob/main/parts/part1-core.md).
